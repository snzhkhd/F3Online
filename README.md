# F3Online

Fan project: FOnline-style (authoritative server + thin client + scripts) multiplayer
reimplementation of the Black Isle *Fallout 3 / Van Buren* tech demo.
Requires the original F3_Demo game data (not included, never committed).

Layout: `tools/` (grptool etc.), `engine/` (common, server, client), `scripts/` (Lua game logic), `docs/` (reverse-engineered formats).
